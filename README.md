# GitShare DevCard

[![CI](https://github.com/dontrushit/GitShare_DevCard/actions/workflows/ci.yml/badge.svg)](https://github.com/dontrushit/GitShare_DevCard/actions/workflows/ci.yml)

A site that looks at a public GitHub profile: languages, repos, how the code is put together, rough level. UI in RU/EN.

Stack: ASP.NET Core 8 + React. Architecture text can go through an LLM. No model key is fine: it still reads the files and uses rules.

## Run it

You need .NET 8, Node 20+, Postgres, and a GitHub PAT (`public_repo` is enough). Do this from the repo root, or pass `--project src/GitShare.Api` — `user-secrets` will not find a project in the root.

```powershell
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Port=5432;Database=gitshare;Username=postgres;Password=YOUR_PASSWORD" --project src/GitShare.Api
dotnet user-secrets set "GitHub:Token" "ghp_..." --project src/GitShare.Api
dotnet run --project src/GitShare.Api --launch-profile http

cd src/GitShare.Client
npm install
npm run dev
```

### Model API (optional)

The GitHub PAT is **not** a model key. GitHub Models is retired. Do not put keys in `appsettings.json` (that file is committed). Set all three secrets, then restart the API.

Claude (OpenAI-compatible endpoint):

```powershell
dotnet user-secrets set "AI:ApiKey" "sk-ant-..." --project src/GitShare.Api
dotnet user-secrets set "AI:BaseUrl" "https://api.anthropic.com/v1" --project src/GitShare.Api
dotnet user-secrets set "AI:ModelId" "claude-haiku-4-5" --project src/GitShare.Api
```

Groq (free tier, same shape):

```powershell
dotnet user-secrets set "AI:ApiKey" "gsk_..." --project src/GitShare.Api
dotnet user-secrets set "AI:BaseUrl" "https://api.groq.com/openai/v1" --project src/GitShare.Api
dotnet user-secrets set "AI:ModelId" "llama-3.3-70b-versatile" --project src/GitShare.Api
```

Any other host that speaks `POST {BaseUrl}/chat/completions` with a Bearer key works the same way.

On startup the API log should show that URL and model, not `AI:ApiKey не задан`. After **Обновить данные**, the architecture panel subtitle is «Сгенерировано моделью» / `Generated by model`. Without a key it stays «По правилам, без модели». If JSON from the model does not parse, it falls back to rules and the request is still billed.

UI: http://localhost:5173
API: http://localhost:5188

Docker: copy `.env.example` to `.env`, then `docker compose up --build`. App is at http://localhost:8081.
